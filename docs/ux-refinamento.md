# Refinamento visual e experiência do usuário

## O que foi ajustado

- alinhamento mais estável das tabelas e cabeçalhos
- melhor hierarquia visual em botões e ações principais
- feedback claro em hover, foco e interações
- reforço de legibilidade em temas claros e escuros
- opções de temas acessíveis para uso do sistema

## Skills utilizadas

- `design-better`: hierarquia visual, acessibilidade, feedback e polish
- `tailwind-design-system`: tokens de design e organização visual do CSS
- `ux-writing`: melhoria de clareza e percepção da interface

## Observação

Como o projeto não possui um arquivo `docs/design.md` antes do ajuste, o trabalho seguiu as convenções visuais já existentes no código e consolidou as novas opções de tema em um conjunto claro de tokens semânticos.
